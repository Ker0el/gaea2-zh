## 词条格式

- 一行一条，`英文=中文`，`#` 开头是注释，空行忽略。
- **访问键写作 `文本(_X)`** —— 那个拉丁字母要保留，否则 `Alt+字母` 快捷键会失效：

  ```
  _File=文件(_F)
  _Open...=打开(_O)...
  ```

- **有些键首尾带空格**，那是句子被拆进了不同控件，空格必须原样保留。

## ⛔ 不要翻译这些

`00_PROTECTED.md` 里列了一批**绝对不能翻**的串。

它们不是显示文字，是**查图标、查格式用的键** —— 译成中文就查不到了，按钮会变空白。往词条里加东西之前，先看一眼那份清单。

## 校对基准

按 Gaea **2.3.1** 校对。其它版本可能有个别对不上。

`10_enums.txt` 里的枚举取值登记了**两种写法**：Gaea 显示时会把驼峰拆开（`Eroded2` → `Eroded 2`），所以「原样」和「拆开」都要有对应的键。
